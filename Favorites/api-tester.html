Why a local relay?

Swagger works because it is hosted on context.reverso.net — same origin as the API, so the browser allows the call. This page is on localhost, so a direct browser call is blocked by CORS. The relay only forwards the exact same request; it does not change the payload. Open this UI via http://localhost:3847/ (not as a file).
