# Android Favorites quiz tester

Maestro plays Reverso → Vocabulary → Favorites → Quiz and logs presented terms for comparison against a Favourites corpus from the web SRS game tester.

**Whenever you start a new run, follow this document only:**

→ **[android-quiz-compare-runbook.md](./android-quiz-compare-runbook.md)**

It covers archive → export into `Android_testing/` → term logger → pick device → Maestro → score (choose corpus).
