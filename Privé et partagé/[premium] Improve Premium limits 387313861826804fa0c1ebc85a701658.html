👀 VIEWING IN FAVORITES / LIST PAGE
API GET /favourites returns the first 40 elements of the stored 200 when free user.

Added object to the response in case the user is free:
"freemiumLimit": {
"limitReached": true,
"storedItems": 67,
"maxAllowed": 40
}

limitReached means that the free limit for items that can be displayed was reached.
storedItemsis the current number of favorites in the DB for that user.
And maxAllowed is the max number of favourites that can be displayed.



⭐️ SAVING EVENT
API GET /favourites/hashes or variant GET /favourites/hashes-ids request, that are usually requested once per page where we want to mark the current Favourites in the page, will contain a new object in the response:
"freemiumLimit": {
"limitReached": true,
"storedItems": 208,
"maxAllowed": 200
}

limitReached means that the free limit for items that can be stored was reached.
storedItemsis the current number of favorites in the DB for that user.
And maxAllowed is the max number of favourites that can be stored.
